# Estudos de front-end

Exercícios e pequenos projetos de HTML, CSS, JavaScript e React que fiz no curso técnico do SENAI e em cursos online, entre 2024 e 2025.

Cada pasta era um repositório separado. Juntei tudo aqui com o histórico de commits original para deixar o perfil mais organizado. São trabalhos de aprendizado: o código mostra a evolução, não um padrão de produção.

## Como abrir

Os exercícios de HTML, CSS e JavaScript abrem direto no navegador pelo `index.html` de cada pasta.

Para o projeto React:

```bash
cd react/meu-primeiro-react
npm install
npm run dev
```
